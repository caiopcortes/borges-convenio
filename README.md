# Borges — Dashboard de Convênios

Dashboard de gestão de convênios (Cassi, Bradesco, etc.) com 3 lentes:
Geral, Sem Convênio e Convênio (com subfiltros por operadora, liminar e tipo).

Lê os dados da aba "Convênios" da planilha Google Sheets publicada como CSV.

## Rodar localmente
```
npm install
npm run dev
```

## Deploy
Conectar o repositório ao Vercel — detecta Vite automaticamente.
